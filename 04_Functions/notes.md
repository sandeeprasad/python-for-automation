What is the difference between print vs return?
print is used just to print the output on the screen and disappears afer that. The value of print cannot be reused.
return is used to return a value that can be used to perform further actions.
add = print(a+b)
print(add*10)
this will throw an error because the return type of print is considered as none. So python has no idea what none*10 is
add = return(a+b)
print(add*10)
this will give an integer output because the value of a+b is stored in the memory and is reusable.
